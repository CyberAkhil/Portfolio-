Claude-like AI chatbot

RAG-powered assistant that retrieves document context before answering — cutting hallucinations on domain-specific queries compared to a raw API call — served via FastAPI with sub-second response latency.

  • Gemini 1.5 Flash backend with ChromaDB vector store — sub-second retrieval latency.
  • RAG pipeline reduces off-topic responses by grounding every answer in uploaded documents.
